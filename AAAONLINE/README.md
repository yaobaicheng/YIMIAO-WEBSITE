# YIMIAO HUANYU 官网｜新手修改说明

这个网站有中文、英文、印尼语。大页面的图片和颜色设置都放在 `index.html` 对应页面开头，已用“第1页”到“第8页”标明；小图片仍在 `content.js` 对应项目附近。

## 0.8 版本改了什么（先看这里）

1. **企业画廊可以点开图片了**：点击有图片的卡片会放大；没有图片的卡片显示“＋”占位，不会破图。
2. **产品图加载更快**：卡片会自动使用 `assets/optimized/` 里的 WebP 小图；没有小图时自动用原图，不会显示空白。
3. **外文长文字不再盖住图片**：产品、服务、方案的文字最多显示固定行数，超出显示省略号；点击卡片可在弹窗里看完整内容。
4. **服务支持页的英文/印尼语已修好**：卡片上的“咨询 / 售后 / 产品”改成随语言切换的 `label`。
5. **大图页面恢复背景遮罩**：每页新增 `--page-photo`，用来调大图透明度；背景色会以渐变压在照片上方，文字更清楚。

### `--page-photo` 怎么调

在 `index.html` 对应页面的 `style` 里找到这一行：

```html
--page-photo:0.55
```

- `0`：完全看不到照片，只看到本页背景色。
- `1`：照片原图完全不透明。
- 文字压在照片上时，建议 `0.4` ～ `0.6`；照片只做小装饰时，建议 `0.1` ～ `0.2`。

### 怎么换大图

1. 把新图片放进网站的 `assets` 文件夹。
2. 在对应页面那一行，把 `data-page-image="assets/旧图片名.jpg"` 改成真实文件路径，例如 `data-page-image="assets/hailiang-banner.jpg"`。
3. 保存并刷新网页。页面会自动检查图片；路径为空或图片不存在时，不会出现破图或难看的空白色块。
4. 如果文字压在照片上不好读，改同一行的 `--page-photo`：数字越小，照片越淡、背景色越明显。

### 怎么换颜色

就在同一行改这四个颜色值，不需要打开 `styles.css`：

- `--page-bg`：页面背景色，也是大图遮罩的颜色
- `--page-text`：标题和正文文字色
- `--page-accent`：按钮、重点和数字的主色
- `--page-soft`：浅色背景和装饰色

颜色值使用 `#` 加六位代码。例如蓝色 `#1689E8`、浅蓝 `#EAF5FF`、深蓝 `#123F69`。每页各有自己的调色板，改一页不会自动改其他页。

## 二、小图片：改 `content.js`

- **产品图片**：搜索 `"products": [`，找到对应产品的 `"image": "assets/product-01.jpg"`。
- **解决方案小图**：搜索 `"solutions": [`，修改对应项目的 `image`。
- **服务卡片小图**：搜索 `"support": [`，修改对应项目的 `image`。
- **服务卡片大字**：同一项里的 `"label"`，例如 `"zh": "咨询"`、`"en": "Consult"`、`"id": "Konsultasi"`。
- **企业画廊小图**：搜索 `"gallery": [`，修改对应项目的 `image`。有图片时点击可放大；`image` 留空会显示“＋”占位。
- **微信二维码**：搜索 `"contactLinks": [`，找到 Andy 或 Jack 的二维码项目，修改它的 `image`。
- **公司 LOGO**：在 `content.js` 开头的 `assets` 里修改 `logo`。

所有图片都先放进 `assets` 文件夹，然后填写文件名和路径。二维码和画廊图片在网页上可以点击放大，点击遮罩、关闭按钮或按 `Esc` 关闭。

### 产品图为什么快

产品卡片会自动去 `assets/optimized/` 找同名的 `.webp` 小图。例如：

- `content.js` 里写 `"image": "assets/铜盘管.png"`
- 网页卡片自动使用 `assets/optimized/铜盘管.webp`
- 点开大图弹窗时仍使用原图 `assets/铜盘管.png`

新加的图片没有 WebP 小图也没关系，会自动回退到原图。想更快的话，把新图另存一个同名 `.webp` 放进 `assets/optimized/` 即可。

## 三、怎么预览和发布

本地预览时双击 `index.html`。发布网站时，把 `index.html`、`styles.css`、`main.js`、`content.js` 和整个 `assets` 文件夹一起上传，不能只上传 HTML。修改后刷新网页检查桌面和手机显示。
